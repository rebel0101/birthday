# Shalu / Gulabo — GitHub Pages Birthday Website

## Upload to GitHub
Upload the CONTENTS of this folder into the ROOT of your `birthday` repository.
Do not upload only the HTML/CSS/JS files: upload the `images` folder too.

Required structure:

```text
birthday/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    └── shalu.jpg
```

The Memories section loads the photo from `./images/shalu.jpg`.
Keep the filename exactly `shalu.jpg` (lowercase).

## Publish
After committing all files, open repository Settings → Pages and confirm GitHub Pages is publishing from the `main` branch and `/ (root)`. Wait for deployment, then hard-refresh the site.

The layout includes responsive styling for desktop, tablet, and mobile. Microphone and vibration behavior depends on browser/device permissions and support.
